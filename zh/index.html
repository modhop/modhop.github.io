常见问题

问题解答

ModHop 免费吗？

是的。ModHop 完全免费，没有广告，也不需要账号。

它会改动我现有的实例吗？

只会改动你选为目标的实例。被替换的文件会先复制到备份文件夹。好友发给你的实例总是会作为新实例创建。

模组从哪里来？

来自 Modrinth。ModHop 在使用每个文件前都会校验其哈希值。不在 Modrinth 上的模组会列出来，方便你自己添加。

为什么 Windows 或浏览器会对这个文件发出警告？

ModHop 还很新，尚未使用付费证书签名，所以 Windows 和浏览器还不认识它。请选择“保留”，或“更多信息”→“仍要运行”。

支持 Forge 和 NeoForge 吗？

支持，只要启动器本身支持它们。Dawn 的实例使用 Fabric，所以 Forge 和 NeoForge 实例会迁移到 Modrinth App 或 Prism Launcher 等启动器。
